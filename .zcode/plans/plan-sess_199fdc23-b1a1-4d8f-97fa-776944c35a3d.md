## 阶段 1：后端真实 BUG（commit 1）

### 1.1 SMTP 无超时挂起 — `internal/tool/builtin/email.go`
- `sendSMTP` 签名加 `ctx context.Context` 为第一个参数。
- 隐式 TLS 分支（465）：镜像 `imapConnect` 模式，用 `net.Dialer{Timeout: 20*time.Second}.DialContext(ctx, "tcp", addr)` 拨号，再用 `tls.Client(conn, tlsCfg)` + `conn.HandshakeContext(ctx)` 包裹（context、net、tls、time 已 import）。
- STARTTLS/plain 分支（`smtp.SendMail`）：标准库不支持 ctx/超时，外层用 `context.AfterFunc(ctx, ...)` 或 select 包装 30s 超时兜底，至少保证 ctx 取消能中断长期挂起；并在注释说明限制。
- 调用点 `emailSend.Execute`(L249)：传入 `ctx`。

### 1.2 apply_patch 破坏非 UTF-8 编码 — `internal/tool/builtin/apply_patch.go`
- `fileChange` 结构体加 `enc fileenc.Kind` 字段（确认 apply_patch.go 已 import fileenc，否则补 import）。
- Phase1 读取处（hunkUpdate L353、hunkDelete L339）：把 `oldContent, _, err` 改成 `oldContent, enc, err`，存入 `fileChange.enc`。
- Phase2 update 分支(L399)：删掉"重新读 enc 又丢弃"两行，改用 `writeFileEncoded(c.path, c.newContent, c.enc)`。
- Phase2 move 分支(L407)：用 `writeFileEncoded(c.movePath, c.newContent, c.enc)`（从原文件继承编码），替换 `0`。

### 1.3 rebuild() 并发泄漏 controller — `desktop/settings_app.go:680-688`
- else 分支（`tab.Ctrl != oldCtrl`，已被并发 rebuild）：先 Close 当前 `tab.Ctrl` 并 releaseSharedHost，再 Close `oldCtrl` 并释放，最后赋新 ctrl。确保任意路径下被替换的 controller 都被清理。

### 1.4 Windows HWND 泄漏 — `screenshot_hotkey_windows.go` + `estop_hotkey_windows.go`
- 声明 `procDestroyWindow`（user32）。
- 两文件 `Stop()` 增加 `DestroyWindow(hwnd)`（若 hwnd 非 0）。

### 1.5 RAG 6 个读函数漏锁 — `internal/rag/entities.go`
- CountEntities(274)、CountRelations(282)、TopEntities(296)、TopRelations(424)、EntityExists(1507)、EntityEmbeddingStatus(1519)：在 normalize 之后、DB 访问之前加 `s.mu.Lock(); defer s.mu.Unlock()`（匹配现有 Mutex 模式）。

### 1.6 RAG ImportText 漏 body_raw — `internal/rag/store.go:593`
- INSERT 改为 `(collection, path, chunk, body, body_raw) VALUES (?, ?, ?, ?, ?)`，实参加 `expandCJKBigrams(c), c`（与 Import/ImportContent 一致）。

### 1.7 crash detail 按字节截断 — `desktop/crash_app.go:43-45`
- import `"unicode/utf8"`。
- 改为按 rune 边界截断：`detail = string([]rune(detail)[:min(n, runeCount)])` 或用 `utf8.DecodeLastRune` 回退。保证有效 UTF-8。

### 1.8 glob 截断提示缺右括号 — `internal/tool/builtin/glob.go:303`
- `"\n... (%d more"` → `"\n... (%d more)"`。
